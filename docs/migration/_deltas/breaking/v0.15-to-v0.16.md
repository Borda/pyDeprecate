- **An operand after `--` is always a path, never the legacy positional version.** `pydeprecate expiry -- src/pkg 2.0` now treats `2.0` as a second path instead of reading it as the version, and exits `2` when no such path exists. Pass `--version 2.0`.
- **A second positional version on `expiry`, `all` and `status` is deprecated.** With two positionals, the second is a path first. It is read as a version only when it names no path or findable module and parses as one; that spelling prints a notice on stderr and stops working in v1.0. Pass `--version` instead; passing both exits `2`.
- **The empty `cli` extra is removed.** The `pydeprecate` command needs no dependency, so replace `pyDeprecate[cli]` with the base package, or with `pyDeprecate[audit]` when you use the audit extras. `pip install 'pyDeprecate[cli]'` still installs, with pip's warning that the extra does not exist.
