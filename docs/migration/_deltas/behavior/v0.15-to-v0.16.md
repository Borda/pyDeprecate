- **`read_only=True` proxies block six more methods.** `sort`, `reverse`, `popitem`, `difference_update`, `intersection_update` and `symmetric_difference_update` now raise `AttributeError` instead of changing the wrapped list, dict or set. The guarded names go from 10 to 16, and a custom method with one of these names is blocked too.
- **A proxy with a callable `target` and `args_mapping` shares one warning budget per call.** `deprecated_class` and `deprecated_instance` emit one call-level warning per call instead of one per renamed keyword, and its message names the replacement rather than each renamed keyword. A test that counted or matched one warning per renamed keyword now changes.
- **Audit reports a function bound under several names under its own public name.** When an alias used to sort first, the row and its finding id carried the alias. A name-based allowlist, `--ignore` pattern or committed snapshot keyed on that alias needs the function's own name instead.
