- **`__deprecated__` is now a plain PEP 702-conformant message string, not the `DeprecationConfig` object.** The config object moved to `__deprecation_config__`.

    Code reading `func.__deprecated__.target`, `.deprecated_in`, `.args_mapping`, or any other config field now gets a plain `str`. So does code checking `isinstance(func.__deprecated__, DeprecationConfig)`. It either raises `AttributeError` or evaluates `False`.

    Replace direct reads with the public `get_deprecation_config(obj)` helper. It also falls back to a legacy `__deprecated__`-as-config layout for objects built by a pre-v0.13 pyDeprecate release. This affects every wrapper kind — functions, methods, class proxies (`deprecated_class`), instance proxies (`deprecated_instance`), and modules (`deprecated_module`).
