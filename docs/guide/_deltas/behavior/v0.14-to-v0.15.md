- **Calls that need no forwarding preserve the caller's positional and keyword argument form.** A call that needs no forwarding, rename or extra argument reaches the source exactly as made; a call forwarded to a callable target is passed by keyword, except positional-only parameters and surplus `*args`, which stay positional. A custom stream that raises no longer leaves warning bookkeeping or emission context stuck, and on a deprecated proxy a warning that fails to deliver does not spend the warning budget; a decorated function still spends it.
- **Warnings that reported a pyDeprecate frame now point at the caller.** Call-time warnings already named the user's call site; the remaining ones, notably the inner warning of a stacked deprecation chain, now carry the caller's line and module too. A warning filter keyed on `module="deprecate"` that matched those warnings no longer does, so they surface, and raise under `-W error`. Key filters on the calling module instead.
- **Async proxy warnings are emitted when the underlying awaitable or async iterator is obtained.** A later failure or exhaustion during `await` or `__anext__` still consumes the warning budget. If the warning itself fails, a coroutine the wrapped call created is closed, while one the wrapped object holds as an attribute (or is) is left usable. `next()` on a deprecated proxy now warns before the wrapped iterator advances, so a failed warning consumes no item; calling the proxy also warns first, as `@deprecated` does, while other synchronous operations still warn only after success, and in-place operators and `defaultdict` subscripts keep their effect if delivery fails.
- **A custom `stream` is called exactly once, with its signature read before the call.** A stream that declares `**kwargs` receives `stacklevel=` and must accept or drop it (forward it to `warnings.warn` or `logging.warning`; `print(msg, **kwargs)` raises `TypeError`). Declare `def sink(msg)` to receive the message alone. A bare `(*args, **kwargs)` `functools.wraps` pass-through is judged by the callable it wraps, also when a `functools.partial` binds it, and a stream whose only parameter is named `stacklevel` receives the message alone.
- **`skip_if` now covers item and in-place writes.** With `skip_if` active, `proxy[key] = value`, `del proxy[key]` and in-place operators write to the wrapped object and the read-only guard does not apply. A fatal proxy (`as_exception=True`) raises `DeprecatedError` before a subscript, iteration or mapped attribute read touches the wrapped object.
- **Deprecated generators warn on the first iteration, not at the call.** A deprecated generator function keeps `inspect.isgeneratorfunction` and a deprecated async-generator function keeps `inspect.isasyncgenfunction`, so pytest `yield` fixtures run their setup and teardown. The warning, the `num_warns` budget, `skip_if`, argument binding and an `as_exception` / `as_exceptions()` error now resolve on the first `next()` / `__anext__()`; a generator that is never iterated never warns. Move `pytest.warns()` and `pytest.raises()` around the first iteration, and keep `as_exceptions()` active at that step.
- **An empty-string `args_mapping` value keeps the argument.** Under `@deprecated`, `args_mapping={"old_arg": ""}` now passes `old_arg` through under its old name, as `deprecated_class` always did, so a `**kwargs` target receives it; only `None` drops an argument. Map the argument to `None` if you relied on `""` dropping it.
- **Proxies carry only the protocols of the wrapped object or its replacement.** A deprecated `dict` is no longer `callable()`, an `Iterator`, `os.PathLike`, `Awaitable` or `AsyncIterable`, and a protocol the object disables stays disabled. `type(proxy) is _DeprecatedProxy` is now `False`; use `isinstance(proxy, DeprecationProxy)`. The generated proxy subclasses cannot be pickled by reference.
- **Forwarding to a `classmethod` checks the source's shape at decoration.** Any receiver name works (`klass`, `mcs`), but a source with no leading positional parameter, or a later parameter named like the target's receiver, raises `TypeError` at decoration, and a static or plain source given a non-class first argument raises `TypeError` before warning.
- **CLI arguments follow `argparse`.** Spellings only the Fire-based CLI accepted exit `2`: a quoted literal such as `--version '"0.10"'`, a list literal in `--exclude` (pass comma-separated patterns), a table in `--min-grace` (set it in `pyproject.toml`), `--path=pkg`, short flags such as `-r`, an empty `--report-json=`, abbreviated option names and a second positional path. A boolean flag given a value accepts only `true`, `false`, `1` or `0`; use the bare flag or `--no-<flag>` otherwise.
- **CLI exit codes changed.** `check` and `all` exit `1` on misconfigured targets and inner-order `@property @deprecated` wrappers, which used to pass. A scan error or internal error exits `3` instead of `1`, and `--exit-zero` masks neither `2` nor `3`. A single `.py` file, a directory holding several packages, or a name that is neither a path nor an importable module exits `2`. Check how CI steps treat `2` and `3`.
- **`deprecated_module(stream=None)` warns at the call.** An explicit `stream=None` still delivers through `warnings.warn` but emits a `FutureWarning`: in v1.0 it silences the module warning, and the `num_warns` default changes from `-1` to `1`. Omit `stream` for today's delivery and pass `num_warns=-1` to keep a warning on every access.
- **`DeprecationWrapperInfo.empty_mapping` and `identity_mapping` warn with `FutureWarning`.** Reading the deprecated aliases now emits `FutureWarning` on every access instead of `DeprecationWarning`, and raises under fatal mode; read `empty_args_mapping` and `identity_args_mapping` instead.
