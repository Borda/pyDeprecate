- **Calls that need no forwarding preserve the caller's positional and keyword argument form.** A call that needs no forwarding, rename or extra argument reaches the source exactly as made; a call forwarded to a callable target is still passed by keyword. A custom stream that raises no longer leaves warning bookkeeping or emission context stuck, and a warning that fails to deliver does not spend the warning budget.
- **Warnings are attributed to the caller's module.** They point at the user's call site and carry the caller's module name, so a warning filter keyed on `module="deprecate"` no longer matches them: an `ignore` filter that silenced them before now lets them through, and they raise under `-W error`. Key filters on the calling module instead.
- **Async proxy warnings are emitted when the underlying awaitable or async iterator is obtained.** A later failure or exhaustion during `await` or `__anext__` still consumes the warning budget. If the warning itself fails, a coroutine the wrapped call created is closed, while one the wrapped object still holds is left usable. `next()` on a deprecated proxy now warns before the wrapped iterator advances, so a failed warning consumes no item; calling the proxy also warns first, as `@deprecated` does, while other synchronous operations still warn only after success, and in-place operators and `defaultdict` subscripts keep their effect if delivery fails.
- **A custom `stream` is called exactly once, with its signature read before the call.** A stream that declares `**kwargs` receives `stacklevel=` and must accept or drop it (forward it to `warnings.warn` or `logging.warning`; `print(msg, **kwargs)` raises `TypeError`). Declare `def sink(msg)` to receive the message alone. A bare `(*args, **kwargs)` `functools.wraps` pass-through is judged by the callable it wraps, also when a `functools.partial` binds it, and a stream whose only parameter is named `stacklevel` receives the message alone.
- **`skip_if` now covers item and in-place writes.** With `skip_if` active, `proxy[key] = value`, `del proxy[key]` and in-place operators write to the wrapped object and the read-only guard does not apply. A fatal proxy (`as_exception=True`) raises `DeprecatedError` before a subscript, iteration or mapped attribute read touches the wrapped object.
