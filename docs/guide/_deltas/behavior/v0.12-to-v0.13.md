- Griffe's `RuntimeDocstrings` extension now scopes its docstring-replacement guard to pyDeprecate's own `__deprecation_config__` metadata (`get_deprecation_config(obj) is not None`). This replaces a bare truthiness check on `__deprecated__`. A foreign object decorated only with the stdlib's `warnings.deprecated` / `typing_extensions.deprecated` previously passed that truthy check too. Such an object has a string-valued `__deprecated__` and no pyDeprecate metadata. It no longer passes the check, since it was never meant to be replaced.
