- Griffe's `RuntimeDocstrings` extension now scopes its docstring-replacement guard to pyDeprecate's own `__deprecation_config__` metadata (`get_deprecation_config(obj) is not None`) instead of a bare truthiness check on `__deprecated__`. A foreign object decorated only with the stdlib's `warnings.deprecated` / `typing_extensions.deprecated` (string-valued `__deprecated__`, no pyDeprecate metadata) previously passed that truthy check too; it no longer does, since it was never meant to be replaced.
