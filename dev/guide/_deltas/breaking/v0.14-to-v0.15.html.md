- **A function `deprecated_instance` stored as a class attribute now binds like a method, and only plain functions do.** Instance access passes `self` to the wrapped function; use `staticmethod(deprecated_instance(...))` for static-style access. A `functools.partial`, bound method, builtin or Cython binding callable is served unbound and silent instead, so a deprecated `partial` class attribute is no longer bound by Python.
- **`functools.partial`, `partialmethod` and `singledispatchmethod` sources now raise `TypeError` at decoration.** This includes a named partial (given a `__name__` through `functools.update_wrapper`) that 0.14 accepted. Wrap the object in a plain `def` that calls it and decorate that `def`.
